# Favas K — Portfolio

Personal portfolio website for Favas K, Full Stack Developer.

Built with [Next.js](https://nextjs.org), Tailwind CSS, shadcn/ui, Framer Motion, and Magic UI.

## Getting Started

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) to see the result.

## Editing Content

All personal data (name, avatar, work experience, education, skills, projects, contact links) lives in a single file:

```bash
src/data/resume.tsx
```

The hero photo is served from `public/favas.jpg` — replace that file to swap the image.
